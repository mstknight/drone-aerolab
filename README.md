# AEROLAB · 无人机飞行实验室

React + Vite + Three.js 交互式无人机气流与姿态控制实验室。首版以 X 型四旋翼定点悬停为核心：可选择恒定风、阵风、周期变风、垂直气流、相关扰动和障碍尾流，实时查看粒子、风速矢量、速度切片、姿态、位置误差与四个电机输出。

## 使用

```sh
npm install
npm run dev
```

页面包含三个工作区：

- **飞行实验**：200 Hz 固定步长六自由度简化动力学，固定电机、姿态稳定、定点悬停三种控制模式；支持自由、跟随、俯视和侧视相机。
- **实验对比**：在相同风场、随机种子和初始状态下比较三种控制模式，统计最大偏差、RMS 误差、最大倾角、饱和时长和恢复时间，并支持回放。
- **模型与 CFD**：导入外观 GLB、保存/载入实验 JSON、导出 CSV；导入固定世界坐标三维速度场，或启动独立无人机 CFD 基准案例。

```sh
npm run test:flight   # 动力学、风场、记录格式验证
npm run build         # 生产构建
npm run test:cfd      # 历史 CFD 管线测试
npm run cfd:drone     # 生成无人机 body-only 固定姿态 CFD 案例
```

## 数据与适用边界

实时场由同一个 `sampleWind(position, time)` 同时提供给动力学、粒子、箭头和探针；风向表示气流运动方向。解析扰动使用固定种子和连续空间/时间函数，不使用逐帧独立随机数。姿态使用四元数积分，渲染帧率与物理步长解耦。

导入速度场要求 `drone-wind-grid-v1`、`m/s`、`world-z-up`、`fixed-world`、来源字段和有限的三线性网格数据。域外采样会停止实验。导入 GLB 只替换外观，质量、惯性、重心和旋翼中心仍由机型参数定义。

浏览器仿真是可重复的教学与可视化模型，参数未经实测标定，不能直接用于飞控部署或安全决策。无人机 CFD 案例是固定姿态 body-only 代理，不包含瞬态阵风、旋翼执行器盘和详细桨叶；通过网格、收敛和实验检查后才能用于校准。原车辆长方体 CFD 页面和数据保留为历史基准。

详细实施和验收项见 [无人机气流与姿态仿真实施工作流](docs/无人机气流与姿态仿真实施工作流.md)。
